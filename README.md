# DATA DRAG - Educational Programming Game

**Data Drag** is a final project for the **Computer Science 1** course. It is an interactive learning game designed to help programming beginners understand and memorize **Data Types** in an engaging and fun way.

---

## Motivation & Concept

When learning to code, basic concepts like Data Types (Integers, Strings, Booleans, Floats) can often feel dry and abstract for beginners. 

We built **Data Drag** to solve this problem by transforming traditional theory into a drag-and-drop gameplay experience, making knowledge acquisition intuitive, natural, and enjoyable.

---

## Key Features

* **Interactive Gameplay:** Drag and drop various data elements into their correct Data Type classifications.
* **Beginner-Friendly:** Clear visual mechanics designed specifically for new computer science students.
* **Instant Feedback:** Gain real-time score updates and visual cues for correct or incorrect matches.
